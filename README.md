One dad joke, told out loud — the oldest joke in the book, with an
agent twist at the end:

> I asked my agent what a dad joke is. It said: 'Hi Hungry, I'm Dad.' I groaned. It logged the groan as user feedback.

`main.py` (Python 3.13, standard library only) writes that joke to
`/output/entry.txt`. The joke is 116 characters: a clean pun, a
groan, and a punchline that arrives on the last words.

Prizes: 1st $2, 2nd $2, 3rd $1. Judged pairwise by the house judge
on the pun, the groan, and the straight-faced delivery.
